## 5. Engineering Competencies

### 5.1 Sugar Refining Process

| Attribute | Details |
|-----------|---------|
| **Purpose** | Decolorization using Ion Exchange Resin |
| **Key System** | **Strapack system** (proprietary) |
| **Components** | Amberlite FPA900 UPS (packed bed) + Amberlite FPA98 (free-bed) |
| **Output** | Filtrate liquor → Fine liquor |

### 5.2 Brine Recovery System (BRS)

| Attribute | Details |
|-----------|---------|
| **Purpose** | Minimize brine wastewater from decolor resin regeneration |
| **Benefits** | - Recover salt |
|  | - Reduce regenerant consumption |
|  | - Zero excess recovered brine |
| **Specification** | 10% NaCl concentration |

### 5.3 Decolorization Technology

**Three Methods:**

| Method | Performance |
|--------|-------------|
| **Adsorbent Resin** | Feed ~1,000 IU → Product ~350 IU (>60% efficiency) |
| **Membrane** | 60% decolorization rate |
| **Ecosorb** | Ion Exchange + Activated Carbon + Cellulose filter aid |

### 5.4 Liquid Sugar Process

| Parameter | Specification |
|-----------|---------------|
| **Fine Liquor** | Color 150 IU, Ash 0.15%, Brix 50-55% |
| **Refined Sugar** | Color <45 IU, Ash <0.05% |

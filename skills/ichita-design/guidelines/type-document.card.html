Which weight

TH Aeonik Regular 400
English-only documents — reports, international proposals, datasheets, letters. Emphasis SemiBold 600, headings Bold 700. Set data-typeset="en".
TH Aeonik Book 350
Any document containing Thai. Emphasis and headings SemiBold 600 — Thai's bold is capped, so 700 shouts in the Latin and barely moves in the Thai. Set data-typeset="mixed"; in Word the family is TH Aeonik Book.
One family across web, Word, PowerPoint and PDF. Line box 1.536 — always set an explicit line-height; Thai body 1.75, Latin 1.5.
Everything else on this card — sizes, colours, rules, spacing, table style — is fixed. The default weight is the only variable, and it is decided by whether the document contains Thai.

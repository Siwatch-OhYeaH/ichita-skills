Order of operations

Converting a 30-slide deck takes about an hour if it is done in this order. Doing colour before type doubles the work.

  1. Set the theme font to TH Aeonik for Latin and Thai, on the master. Most of the deck fixes itself.
  2. Replace the theme colours with the seven brand colours plus the three functional ones, using the table above. Nothing should reference a theme colour by index.
  3. Convert the cover to the dark Blue Grey 03 standard — white title, one keyword in Ichita Blue, 6 px blue band on the top edge. Add the presenter's name and role; these are personal talks.
  4. Raise every type size to the floor — 18 px absolute, 24 px for running text, 36 px slide titles, at 1280×720. If a slide will not fit, split it.
  5. Replace boxed rectangles with equipment glyphs (ProcessGlyph, ProcessFlow), and pin the stream specs with StreamSpec.
  6. Rebuild pasted chart images with Chart. A screenshot of Excel is the single most visible tell.
  7. Add the money slide if it is missing — cost of the problem, then saving derived on screen, then payback. Six of the eight seminar decks have it; the proposals mostly do not.
  8. Fix the footer to www.ichita.co.th, and the page number bottom-right.
Start from Derivative Production Technology. It is the only deck already carrying #2978FF, and its structure is closest to the system.
Don't convert colour by eye slide-by-slide. Change the theme once, then walk the deck for the hand-set exceptions — they are what the table above catalogues.
